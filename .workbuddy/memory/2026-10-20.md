## Git 免密配置（SSH 公钥）

- 仓库 origin 存的是 https 地址，但全局有 `url.git@gitee.com:.insteadof=https://gitee.com/`，实际走 SSH
- `~/.ssh/config` 为 gitee/github/gitlab 指定 `IdentityFile ~/.ssh/id_ed25519_git`
- 问题根因：该公钥未登记到 Gitee 账号，认证报 `Permission denied (publickey)`
- 处理：把 `~/.ssh/id_ed25519_git.pub` 添加到 Gitee（https://gitee.com/profile/sshkeys）
- 验证通过：`ssh -T git@gitee.com` → Hi aoaoyin；`git fetch origin` 免交互成功
- 遗留：`credential.helper=manager` 仍全局开启，仅对 https 生效，不影响现状，未改动
