# .agents/notes

**按来源分两个目录，不要混。**

| 目录 | 内容 | 约束力 |
|---|---|---|
| `decisions/` | **用户做的决策** | 有约束力，照着实现，不要再重新讨论 |
| `research/` | agent 的调研、评估、推演 | 没有约束力，仅供参考 |

## 规矩

- **拿任何一份文档当依据之前，先看它在哪个目录。**
- agent 不得把自己的推演写进 notes 再当成「项目原本的定义」来引用。
- 每一份 decision 都要写清「决策是什么」和「**否掉了什么方案、为什么**」，
  是为了不让同样的讨论再来一遍。
- 用户判定「这不是我定义的」的文档，文件头加 `⛔ 已弃用`，保留只为留出处。

- `research/WS通信架构-ESP32与香橙派双device.md` —— ⛔ 已弃用，用户判定不是他定义的
