# 历史记录与统计

## 命名

- 不新增概念，还是 Entity：`Entity` 表是它此刻的样子，`EntityHistory` 是它过去的样子，落盘代码 `server/core/history.ts`。
- Entity 的身份是 `device_id` + `id` 两个字段，历史表原样沿用，不另造单列 `entity_id`。

## 落盘

- 没有定时器：`pub_entities` 进来一条就落一条，每条电表读数写一行 `EntityHistory`，`ts` 用设备报的 `e.ts`。
- 落盘频率 = 报文频率 ≈ 3.4 Hz，正好一轮 RS485 采集。一轮里三只表各读一次，毫秒 `ts` 让它们各占一个时刻，所以既不丢点也不重复。
- 申报那条 `ts` 是 0，`if (e.ts)` 判假直接跳过，不写历史。
- **不删行**：账本要一直留着给统计做差。10 分钟只是查询窗口，`GET /api/rooms/:device_id/history` 默认 `since = now - 600000`。
- 内存那张表仍是唯一真源，历史只是它的流水。
- 一个库一个 server：`Bun.serve` 抢端口，第二个进程起不来。
- 库开 WAL + `synchronous = NORMAL`：进程崩溃不丢，断电可能回滚最后一笔。

## 表

- `EntityHistory`：`device_id` / `id` / `ts` / `powerW` / `energyKwh`，主键 `(device_id, id, ts)`，外键指向 `Entity` 的主键，`onDelete: Cascade`。
- `ts` 存毫秒：`Entity.ts` 和 `EntityHistory.ts` 都是 `Float`。Prisma 的 `Int` 是 32 位，装不下 `1.7e12`；`Float` 落到 SQLite 是 REAL，2^53 以内的整数精确，JSON 侧仍然是 `number`，不用 BigInt。
- 按实体存，不按房间存：详情页能分别画灯 / 热水壶 / 吹风机三条曲线。
- 主键本身就是「某块表某一秒」，取某时刻的值直接走它，不另建索引。

## 功率与电量

- `powerW`：设备报的瞬时功率，服务实时曲线。
- `energyKwh`：**服务器侧累计电量**，不是设备报的原值。设备报的是它从开机起的累计（类似 HA 的 `total_increasing`），下位机没有持久存储、读数可能归零；归零时接着往上累加（`delta = raw - last`，`delta < 0` 就取 `delta = raw`），所以这一列只增不减。
- 累加在内存里做（`server/core/energy.ts`），启动时从账本最新一行把累计值接上，演示样本与实时数据是一条连续的线。

## 用电量就是做差

- 一块电表从装上到拆掉只有一条单调递增的累计电量，任何「这段时间用了多少电」都是两次取值相减：`结束那一刻的值 − 开始那一刻的值`。
- 查询永远不扫区间，只问「某时刻的值」：`where device_id = ? and id = ? and ts <= ? order by ts desc limit 1`，走主键，一次几十微秒。按天 = 每天问一次，24 小时分布 = 每小时问一次，一次入住 = 问两次。
- 所以不预分桶、不建汇总表、不存账单数字。怎么用见[统计与入住记录](统计与入住记录.md)。

## 时间

- 全服务器的时间只有一个出处：`server/core/util.ts` 的 `now()`（毫秒）。
- 它可以快进：`nextDay()` 给偏移加一天，`POST /api/clock/next-day` 就是它。拨表时把各设备的 `lastSeen` 一起往前挪，免得刚拨完就被失联判定踢掉。
- 统计里的「天」就是服务器时间里的当地 0 点，不另造分组键、不用结算动作。
- 下位机的时间由 `ack_alive` 对时（见[数据模型与协议](数据模型与协议.md)），服务器拨表后它一拍心跳就跟上。

## 接口

- `GET /api/rooms/:device_id/history?since=` 返回该房所有实体窗口内的点，按 `ts` 升序。`since=` 是毫秒时间戳，不传默认最近 10 分钟。
- `GET /api/stats` 见[统计与入住记录](统计与入住记录.md)。

## 曲线

- 页面打开时查一次库回填窗口内的点，之后靠 SSE 每帧推的新值往右攒，前端自己攒数组：同一毫秒后来的帧覆盖功率值，不产生重复点；前端同样只留最近 600000 毫秒。
- 点的 `ts` 用实体自己的 `Entity.ts`，不是前端取 `Date.now()` —— 一条报文里的几只表各有时刻，前端不能替它们编时间。
