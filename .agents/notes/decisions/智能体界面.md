# 智能体界面

## 用什么

- 前端：assistant-ui 的 Vue 绑定，成品 UI 用它注册表里的组件（**上游原样副本，不改**）
- 模型：只有 DeepSeek 官方一家，`@ai-sdk/deepseek`，调用走 `streamText`
- 不引 React 岛，不引 AGUI；**不自造 UI**（assistant-ui 只有 React 版的模型选择器，所以前端不摆下拉）

技术栈关系、上游溯源见 [research/智能体UI-技术栈与落地.md](../research/智能体UI-技术栈与落地.md)

## 模型

- 只有 DeepSeek 官方一个，env 里只有 `DEEPSEEK_API_KEY`
- 前端没有模型选择器，请求体也不带 `model`

## 前端

- 独立页面 `/agent`，侧边栏「AI智能体」进
- 我们自己的前端只有 `web/src/views/AgentView.vue` 一个薄壳：怎么组合、给哪些建议问法
- `web/src/components/assistant-ui/*.vue` 是上游原样副本，界面文案保持上游英文（要动先问用户）
- 主题只管排版和取色，写在 `web/src/styles.css`（元素级重置必须放 `@layer base`，否则会压掉组件的 Tailwind 类）

## 服务端

- `POST /api/chat`：只收 `messages`，跑 `streamText` + 工具循环，回 UI message stream
- 工具只有一个 `em`：跑本项目 CLI（`--json`），让模型拿到真实客房/设备数据
- key 只走环境变量，本机取自 `~/.dsh/.credentials.yaml`

## 三种状态

| 后端 | `Home` | 发消息 |
|---|---|---|
| 没有 | 没按 | 报「Failed to fetch the chat response.」 |
| 有 | 没按 | 正常走 DeepSeek |
| 没有 | 按了 | 前端自己出回答，内容对得上 mock 那两间房 |

`web/src/mock.ts` 里的 `MockChatTransport` 继承 `AssistantChatTransport`（`mock`, `rooms`, `stats` 三个 ref 由 `AgentView` 传进去），`sendMessages` 时看 `mock`：开着就把 `mock.ts` 的 `mockReply()` 分小段吐出来，没开就 `super.sendMessages()` 照旧发请求。判断落在每次发消息，所以切模式不用刷新、上下文也不丢。
