# 智能体界面

## 用什么

- 前端：assistant-ui 的 Vue 绑定，成品 UI 用它注册表里的组件（**上游原样副本，不改**）
- 模型：AI SDK 的 provider 注册制（`@ai-sdk/deepseek` 官方；OpenAI 兼容网关用 `@ai-sdk/openai-compatible`），调用走 `streamText`
- 不引 React 岛，不引 AGUI；**不自造 UI**（assistant-ui 只有 React 版的模型选择器，所以前端不摆下拉）

技术栈关系、上游溯源、现场演示脚本见 [research/智能体UI-技术栈与落地.md](../research/智能体UI-技术栈与落地.md)

## 多模型

- 一行一个模型，写在 `server/agent/models.ts`
- 请求体里带 `model` 就用那个，不带就用默认；没有别的配置
- 现场演示就是**现场注册一个供应商 + 它的模型（4 行）**，再用 `curl` 带 `model` 打一发看效果

## 前端

- 独立页面 `/agent`，侧边栏「AI智能体」进
- 我们自己的前端只有 `web/src/views/AgentView.vue` 一个薄壳：怎么组合、给哪些建议问法、演示模式开关
- `web/src/components/assistant-ui/*.vue` 是上游原样副本，界面文案保持上游英文（要动先问用户）
- 主题只管排版和取色，写在 `web/src/styles.css`（元素级重置必须放 `@layer base`，否则会压掉组件的 Tailwind 类）
- 右上角「演示模式」= 不联网的假 transport（`web/src/mock-agent.ts`），现场 API 不通时兜底

## 服务端

- `POST /api/chat`：请求体带 `model`（可选），跑 `streamText` + 工具循环，回 UI message stream
- 工具只有一个 `em`：跑本项目 CLI（`--json`），让模型拿到真实客房/设备数据
- key 只走环境变量，本机取自 `~/.dsh/.credentials.yaml`
