## 要什么

打开网页就是客房管理页面。

网页是一个**桌面管理后台**，跑在电脑、平板、手机上。它跟大屏是同一套业务的两种终端，不是同一套界面。

## 跟大屏什么关系

大屏 `slintui/` 是**香橙派上那块嵌入式屏**，深色、大字号、远距离看、只有触摸。网页是**管理后台**，浅色、有鼠标。

## 长什么样

整体沿用浅色卡片风，不另起炉灶。

### 配色

颜色只在 `styles.css` 的 `:root` 定义，组件和图表一律 `var(...)` 取用，**任何地方都不写死颜色**：

```css
--bg:#f8fafc          --card:#ffffff        --text:#0f172a        --muted:#475569
--primary:#1d4ed8     --primary-soft:#eff6ff
--green:#15803d       --green-soft:#f0fdf4
--gray-soft:#f1f5f9   --warn:#92400e        --warn-soft:#fffbeb
--border:#e2e8f0      --radius:12px         --shadow:0 1px 2px rgb(15 23 42 / 0.25)
/* 回路配色：一条回路一个颜色 */
--circuit-1:#f87171   --circuit-2:#4ade80   --circuit-3:#facc15
```

**默认色统一**：**没挂回路色的组件**（房级总表、总闸、它们的弧线 / 通电底色）一律 `--primary`，别一个蓝一个绿。Entity 小卡一律挂 `--circuit`；配不上开关的 Entity 按第 1 条回路算，不退默认色。

**回路配色**：一个回路（开关 + 它的电表 + 它在曲线里的那条线）共用一个颜色。取色板 **400 档**（red / green / yellow）——三色亮度一致才协调，也比 600 档柔和；**不用蓝**，蓝留给默认色，不然分不清「这条回路的色」和「默认色」。回路多于 3 条就从头循环。

对应关系靠 entity id 认——**电表 id 就是开关 id 加 `-meter`**（`light` ↔ `light-meter`），`color.ts` 里 `circuitIndex()` 按开关在实体表里的顺序编号。**color.ts 不存任何色值**：组件那边只产出 `var(--circuit-N)` 字符串；Chart.js 那边 `circuitColor()` 现场从主题 `getComputedStyle` 读出真颜色值。

页面底色 `--bg`，卡片底色 `--card`，卡片描边 `1px solid var(--border)`，圆角 `--radius`。**不用深色底，不做大面积渐变、毛玻璃、重阴影。**

### 导航

- **≥ 1024px（桌面）**：左侧竖栏（吸顶、占满视口高），宽 200px，`background: var(--card)`，右边框 `1px solid var(--border)`。竖排导航项。每项高 44px、圆角 10px、左右内边距 10px、图标与文字间距 10px、字号 15px，选中项用 `--primary` 文字 + `--primary-soft` 底色。
- **< 1024px（平板、手机）**：左侧栏隐藏，改成**底部固定 tab 栏**，高 64px，`background: var(--card)`，上边框 `1px solid var(--border)`，另外留 `env(safe-area-inset-bottom)`。两个 tab 等分宽度，图标在上文字在下，图标 22px、文字 14px，选中项同样用 `--primary` + `--primary-soft`。

导航：

- 房子图标 **客房管理**（`/rooms`）
- 摄像头图标 **视频监控**（`/camera`）

### 页头与字号

页面顶部一行加粗居中的大标题「民宿智能用电管理系统」（App 里没有页头：每种页面自己挂同一个 PageHeader 组件，状态标签塞进它的插槽）。

**连接状态标签**：胶囊（圆角 999px、13px 字），三态文案「已连接 / 已断开 / 连接中」，文案字符串由 data.ts 出——已连接 `--green-soft` 底 `--green` 字，已断开 `--warn-soft` 底 `--warn` 字，连接中 `--gray-soft` 底 `--muted` 字。

字号：页标题 24px、房名 20px、关键读数 20–32px、正文 16px、辅助信息 13–14px。数字统一等宽数字（`font-variant-numeric: tabular-nums`）。

字体用系统字体，不外链字体。

## 客房管理

打开网页就是客房管理页面，一间房一张大卡片，卡片里直接铺着这间房的电表和开关。≥ 640px 房卡排两列（等宽），窄屏单列。

一个实体都没报过的设备不是客房，不画卡；房里可以没有电表、只有人数计数。搜索把房全滤掉时显示「没有匹配的客房」，还没有客房接入时显示「还没有客房接入」。

### 顶部

页头下面一行放搜索框。

### 客房卡片

一张房卡从上到下四块：房头、房级行、曲线、Entity 区。

**房头一行**，垂直居中：

1. 在线圆点，直径 10px。在线 `--green`，离线 `--muted` 且 `opacity: .5`。
2. 房名，20px、加粗，可换行。房名可以**点一下就地改**，回车提交、Esc 或失焦取消；编辑框灰底、蓝边、圆角 8px。
3. 「在线」/「离线」文字，14px、`--muted`。

**房级行**：横跨房卡、高 140px，在曲线正上方，三样东西两端对齐排开——左边是**房级总表**（功率表边长 120px + 下面一行 13px 的累计 kWh），居中是**竖总闸**，右边是**人数计数**（见下）。

**人数计数**：房级行最右，竖排居中：净人数（数字 34px、加粗、`--primary`、等宽数字，基线旁缀一个 13px `--muted` 的「净」字）→「进 N · 出 N」（13px、`--muted`）→「清零」小按钮（12px 胶囊）。人数是大屏替这间房报的（`people-counter` 实体），跟房在不在线无关。清零只是摆着——怎么下指令还没定，不发请求。

**功率曲线一条**，详见下面「曲线图」。

**Entity 区**：来什么排什么——**先排完这间房所有电表，再排所有开关**，横着铺开，详见下面「Entity 小卡」。

离线房整体 `opacity: .72`，数值照样显示（那是最后上报值）。

删除图标放房头那行的行尾（`margin-left: auto`，房头可换行），点了先二次确认再删。

### Entity 小卡

电表和开关都是横排的小卡，放不下就换行，间距 12px。两种卡不是一个排法：

```css
/* 电表：宽度自适应，180px 是压缩底线 */
.meter { flex: 1 1 180px; min-width: 180px; }
/* 开关：固定 120px 一格 */
```

理由：功率表是个正方形，它要缩到小卡的内容宽度里。小卡 140px 时内容区只剩 116px，弧半径跌到 44px，刻度线只有 8px，指针和数字全糊在一起，读不出来。180px 时内容区 156px，弧半径 59px，刻度 11px，才看得清。

**小卡内容区最小 156px，功率表跟着这个宽度走，但不小于 140px。** 写成一层 `min-width` 兜底：小卡内容宽度小于 140px 时，功率表就停在 140px 不再缩，宁可小卡内部出现一点点横向留白，也不让表缩到不可读。**房级总表是缩小版**：功率表边长 120px，不做 140px 兜底、跟着容器缩，读数字号另缩一档。

**电表小卡**：竖排、居中，名字（14px、`--muted`，缺名字用Entity  id）→ 功率表（正方形，边长 = 内容宽度）→ 「累计 12.40 kWh」（13px、`--muted`、居中）。两种小卡的底色 / 描边 / 圆角 10px / 内边距 12px 共用一个 `styles.css` 类 `.entity-card`，不各写各的；电表的 flex 排法写在房卡组件里（`:deep(.meter)`）。

**开关小卡**：一台闸一张卡，卡宽 120px、竖排。名字在上（14px、`--muted`，缺名字用 Entity id）→ 竖闸体（48×76px、圆角 24px，开为 `--circuit`、关为 `--border`，圆点 40px、`--card` 底色带 `--shadow`，行程 28px，200ms `ease-out`）。**名字是闸上唯一的文字**，开关状态看圆点位置就知道，不写「通电」「断开」。整卡可点，点一下就下发通断令：先本地翻转，下位机 ack 后 SSE 把真实状态盖回来；离线房不可点，未上报时整体 `opacity: .5`。

**整房总闸**：闸体大一号（56×88px、圆点 46px、行程 32px），在房级行里、人数计数左边。状态取全房所有开关Entity 的聚合——**全部** 为 on 才显示 on。点一下把所有开关一起切到相反值，同样真实下发；没有开关的房、离线房都不可点。

### 功率表

手写 SVG，viewBox 100×100 等比缩放，这些照抄不改：

- 满量程 2000 W，功率压到 0–1，指针到顶。
- 弧从 135° 起顺时针扫 270°，缺口留在正下方（不是半圆）。圆头描边，底弧 `--border`、值弧回路面色（没挂回路色就 `--primary`）；功率近 0 时不画值弧——近零长度的圆头线帽会冒出一个圆点。
- 刻度 11 根，每 5 根一根主刻度（更长更明显），从外沿往内收。
- 指针 `--text` 色、带中心圆点；**没上报时指针整个不画**，只是读数写「—」并变细变灰。
- 读数画在弧内正下方，加粗、等宽数字。

## 示数

功率和电量各有各的写法，收在 `web/src/format.ts` 里，房级总表、电表小卡、功率表里的数字都走它，不在组件里各写各的。

**功率**：1000 W 以下写整数瓦 `0 W`、`320 W`；1000 W 起进位到千瓦、保留一位小数 `1.2 kW`。

**电量**：固定两位小数，输入已是 kWh、不做单位换算，返回「12.40 kWh」整串（「累计」前缀由组件拼）。

**没上报**：数字位置写 `—`，不写 0。

## 曲线图

房卡内一条，一块电表一条折线，能看出灯、热水壶、吹风机各在什么水平。

**用 Chart.js 画**，Vue 侧包一层 `vue-chartjs`。按需注册，只引折线、数据点、tooltip 和坐标轴这几样，别 `import "chart.js/auto"`。

**尺寸**：宽度撑满房卡，**高度按档位固定**，不跟着宽度变：

| 视口 | 高度 |
|---|---|
| < 640px | 130px |
| 640–1023px | 150px |
| ≥ 1024px | 170px |

Chart.js 默认按容器尺寸自适应（`responsive: true` + `maintainAspectRatio: false`），高度交给上面这个档位，宽度跟着房卡走，不用自己算缩放。房卡变宽，同一时间窗里的点距自动拉开。

**画法**：每个电表一个 dataset，颜色走回路配色（见上），线宽 1.5px、不画数据点。Y 轴上下限按数据自己伸缩（上下各留 5% 余量、余量最小 1 W，下限不低于 0），**不从 0 起**——固定从 0 起会把小幅波动压平。X 轴最多 6 个刻度、不斜排。

**对齐**：labels 取全部电表时间戳的并集，没点的时刻补 null；series 按实体 id 字母序。前端自己也只留最近 600 秒的点，与服务端窗口一致。

**悬停**：开内置 tooltip，`mode: 'index'` + `intersect: false`，鼠标落在哪个时刻就列出该时刻所有电表的读数（名字 + 功率），末行是合计。时间标签（tooltip 和 X 轴刻度都算）写成 `HH:MM:SS` 本地时间 —— **只有界面用时间格式，数据层一律 number 秒级时间戳**。

图的观感要收着点，别用 Chart.js 的默认皮：关掉动画（每秒来一帧，动画会互相追），网格线调淡（X 轴干脆不画），tooltip 白底细边框，字体跟着页面的字号走。

边界：还没有历史点时显示「正在加载曲线」；只有一个时间点（按去重后的时间点数算，不是电表数）显示「数据积累中」；历史接口失败就静默不画，**不影响房卡其余部分**；这间房没有电表就整块不渲染（房卡里判，不进曲线组件）。

## 视频监控

一个页头 + 一张卡片，卡片里一张 `<img>`，src 固定 `/api/cv/stream`（MJPEG），宽度撑满、16:9 占位、`object-fit: contain`。见 [server/routes/cv.ts](../../../server/routes/cv.ts)；mock 不覆盖视频。

## 边界

- **开关真实下发**。点单个开关或整房总闸：先把本地状态翻过去，同时 `POST /api/entities/:device_id/:entity_id/switch`（body `{ state }`）；返回值不代表闸已动，下位机 `ack_action_switch` 落 state 后，下一帧 SSE 把真实状态盖回来。离线房不可点。
- 不新建客房：设备接入时后端自己建，见[房间管理](房间管理.md)。
- 不做告警、登录。
- 不引组件库。曲线用 Chart.js，功率表手写 SVG，别的不引。
- 不改 `shared/types.ts`。

## 验收

- 一切宽度都不出现横向滚动，360px 可用、1440px 内容居中限宽。
- 深色一点都没有：页面底色、卡片底色、导航都是上面那套浅色令牌。
- 桌面是左侧竖栏，窄屏是底部 tab，和旧 WebUI 一致；不是顶部深色横栏。
- 功率表在小卡最窄时也读得清：弧、刻度、指针、数字不重叠。
- 曲线一块电表一条线，颜色与回路配色一致；鼠标悬停有 tooltip，列出该时刻各电表读数和合计，合计等于各读数之和。
- 曲线宽度跟着房卡变，高度停在对应档位，不被压扁或拔高。
- 房级行与下面的曲线都横跨房卡，左右两边对齐；总闸右边是人数计数。
- 点正常房的开关或总闸会真的下发通断令，本地先翻、SSE 回流后以真实状态为准；离线房不可点。
- 房卡里能看到这间房报上来的净人数与进/出人数。
- 闸上除名字外没有文字，闸的开合只看圆点位置。
- 功率与电量的写法在房级总表、电表小卡、功率表里一致。
- 六种情形（正常 / 零功率 / 离线 / 无Entity  / 多Entity  / 长名称读数未齐）都不崩、不塌、不叠字。
- `bun run --cwd web check` 与 `build` 通过。
