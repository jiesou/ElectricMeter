## 故事

**主线故事**

- **一句话**：让老旧民宿**不大改线路就能用上**一套看得见、管得住、算得清的用电系统。
- **客户口径**：民宿为主，同一套系统可推广到长租公寓 / 酒店（讲"可推广性、经济性"时用）。

**养老故事**

- 老年人本来就是民宿的顾客，所以"面向老年客人的照护功能"是民宿侧的正常服务，不是另开一条业务线。
- 功能：老人每天都用电水壶，某天忽然没有用电水壶的记录 → 可能出事了 → 触发关怀提醒；另加一个**一键求助**。
- 区域特色：慈溪"智护银龄"刚在试点，是需求真实性的佐证。
- 区域特色：浙江宁波旅游业民宿，我们在景区旁边

**痛点**

- **老旧民宿设施难改善** —— 不想大改、不能大改，也要低成本升级
- **客人走掉忘拔卡费电难节省** —— 空置房间空调照明空耗，人工管不过来
- **用电情况难量化** —— 哪间房、哪个电器用了多少电，说不清

## 一鱼两吃：同一套系统打两个赛道（两个都是主场，完全平行）

硬件是同一套，板子做两块，讲法分两套，**内容各自做满**：

| | 电类赛道 | 信息赛道 |
|---|---|---|
| 讲什么 | 电能表怎么选、用电量怎么算；强电设计、电路改造、电气安全、配电柜、断路器选型 | 界面怎么做、平台怎么搭；数据采集、通信协议、可视化、数字孪生、移动端 |
| 自研计量板 | **外露**：小板子 + 透明亚克力壳，给评委看电路 | **隐藏**：装进 3D 打印小盒固定在配电箱里，对外就是成品电能表 |
| 监控 | —— | 用成品监控系统 |
| **现场技能动作**（技能水平 60%） | **现场焊接 PCB 模块、接线，把电能表串联进回路** | **现场启动服务器后端、开发前端界面、部署系统** |
| 服务器 / 运行环境 | 安全电压台架 + 网孔板 | **Ubuntu Server + Docker 跑服务**；国产化叙事讲"容器化后可迁移到麒麟 / 欧拉" |

## 现场展演装置（效果已想好）

- **主配电装置 = 一块网孔板当配电箱**：上面装真空气开关、**可控断路器（执行通断）**、端子排、线槽，**加挂自研电能表**，并引出摄像头进出的判定线。
  - 对评委的叙事：**外挂集成式改造**，不动民宿原有配电箱，加装计量与通断模块（呼应"不大改线路"）。
- 1~2 个模拟客房，门用 KT 板（舞台表演用，很轻）
- 演出桥段：人走了、烧水壶还在工作 → 矩阵屏亮起 + 滴滴报警声 + 红色感叹号
- 评委全程只看不问，60 分钟必须**有动作、有声音、有画面**
- 分工参考：前端 / 后端 / 数据采集（抓取与算法）三个方向，套 4 人赛队
