# .agents/notes

- [AGENTS.md](../../AGENTS.md)（项目根目录）：**做什么**。项目是什么、现在有什么、还要做什么；每项只提一嘴，并指向对应的 decisions。
- `decisions/*`：**怎么做**。架构、技术实现、代码应该怎么落。
- `research/*`：调研、比较、推演，供复用，不构成项目定义。

## 规矩

- **拿任何一份文档当依据之前，先看它在哪个目录。**
- agent 自己的研究，应写入 `research/`，不得把自己的推演写入 `decisions/`
- 只有用户明确确认的内容，才写入 `decisions/`
