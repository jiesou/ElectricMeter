# 选题头脑风暴（第二轮）：以"岗位群 + 行业"为验收标准

> 输入：7 类主要岗位（群）/技术领域 + 2 个对接行业大类
> 用途：把"专业对接度"变成可打分的硬指标，用它反推选题
> 约束：60 分钟展演、4 人团队、自制硬件、体量足够占地、闭环为"数据采集—研判分析—任务调度—现场处置"

---

## 0. 一句话结论

你的岗位清单里 **4 个岗位群（移动开发、运维、安全、数据）是"必答题"**，
第 3、6、7 类（安全安防 / 通信网络运维 / 卫星通信）是"加分题"。

**最容易漏掉但杀伤力最大的两件事：**
1. **卫星通信（第 7 类）**——绝大多数队伍会漏。一个北斗短报文 / 卫星物联网终端就能把这 7 类**全部点亮**，成本极低、稀缺度极高。
2. **行业大类只给了两个**（互联网服务、软件和信息技术服务）——所以项目必须是**"行业 + 信息技术"的合同**，不能是"电力项目"或"港口项目"。装置是皮，交付物是**软件/服务/数据**。这一条直接决定"应用价值"10% 的给分口径。

## A. 岗位群 → 技术载体映射表（选题时逐条对勾用）

| # | 岗位（群）/技术领域 | 展演中必须出现的"可视动作" | 常见漏项 |
|---|---|---|---|
| 1 | 移动应用开发与服务 | 真机 App 扫码巡检、工单派发、遥测曲线跳动、现场处置一键下发；大屏 3D 点选联动 | 只做大屏不做移动端 → 丢一整类 |
| 2 | 计算机与办公设备维护 | 台架物理接线、防静电、串口/波特率调试、更换模组、外设装配 | 光敲代码不动手 → 丢"手上功夫"分 |
| 3 | 网络安全与安防 | 现场渗透测试、抓包重放、告警联动声光/门禁、策略下发、等保合规清单 | 只讲"我们做了加密" |
| 4 | 数据处理与分析 | 数据采集入湖、清洗、时序库、可视化、标注/AI 训练小样本 | 只有 ECharts 没有数据治理链路 |
| 5 | 通信与信息技术服务 | 客户解决方案讲解、呼叫中心/工单/CRM 界面、移动终端开发、品质管控测试 | 没有"服务"这一面 |
| 6 | 信息通信工程与网络运维 | 光纤熔接/网线端接、VLAN 规划、SDN 策略、故障注入与排除、基站/AP 调测 | 网络只当背景板 |
| 7 | 卫星通信 | 北斗短报文收发、定位/授时、卫星物联网上报、遥感数据落地展示 | **几乎全员空白 → 差异化机会** |

> 记分法：展演脚本里能指认出"可视化动作"的岗位记 1 分，满分 7。
> **目标 ≥ 6 分，且第 1、3、4、6 类必须满。**

## C. 三条"全覆盖"装置设计范式（可直接套）

### 范式 I：多岗席位式大台架（推荐骨架）
一个占地 ≥ 3 m × 2 m 的可拆装台架，物理分区，让 4 名选手各有"工位"：

```
┌──────────── 大屏 / 投影（3D 孪生 + 指挥大屏）────────────┐
│                                                          │
│  [A 区 配电台架]      [B 区 标准 19" 机柜]   [C 区 处置席] │
│  电表/互感器/储能     边缘网关/SDN 交换机     平板 + 真机   │
│  充电桩/光伏模拟      信创服务器/K8s 节点     App 巡检/工单 │
│  接线端子排           北斗短报文终端模块     声光/门禁联动  │
└──────────────────────────────────────────────────────────┘
```
- 体量来源：**19" 标准机柜 + 端子排 + 线槽 + 真表计**，尺寸唬人且是"真的工业件"。
- 4 人分工天然对应：台架接线（B 岗）｜网络与云（C 岗）｜移动端与大屏（D 岗）｜主讲与调度（A 岗，兼安全测试）。

### 范式 II：真信号 + 真扰动（决定技能分高低的关键）
**不要让数据在屏幕上"跳假动画"。** 用真电压/电流源 + 可编程负载，让台架产生真实二次侧量测；
再用**故障注入矩阵**制造必须现场排障的工况且不可预演：

| 注入的故障 | 选手必须做 | 对应岗位群 |
|---|---|---|
| 拔掉 RS485 / 反接 A-B | 万用表查线、恢复、校验点表 | 2、6 |
| 模拟量通道加噪声 / 中性线断开 | 数据清洗规则、谐波分析、重标定 | 4 |
| 交换机端口镜像 + ARP 欺骗 / 违规接入 | 抓包定位、端口安全策略、准入 | 3、6 |
| 网关掉线 / MQTT 断链 | QoS、离线续传、本地缓存补传 | 5、6 |
| 拔掉光纤 / 改 VLAN | 熔接或跳线恢复、VLAN 重规划 | 6 |
| 主站失联 | 北斗短报文兜底上报 | 7 |

> 故障注入本身就是**评委眼里的"难易度"证据**，也是把 60 分钟填满而不空虚的正当理由。

### 范式 III：双场景双活（把"应用价值"讲成合同）
同一套装置、同一套软件，现场切换**两个真实客户场景**（例如"港口岸电" ↔ "园区充电站"），
用**配置驱动**证明可复制推广 + 出具一份 SLA/节能效益报告。
→ 直接命中评分表里的"可推广性、经济性、绿色低碳"。
