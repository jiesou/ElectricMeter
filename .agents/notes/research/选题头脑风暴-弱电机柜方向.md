# 选题头脑风暴（第三轮）：弱电机柜 / 网云骨架 / 纯地面通信

> 本轮的三个硬约束（由上一轮拍板）：
> ① 装置骨架 = **19" 标准机柜 + 网络设备 + 信创服务器 + K8s**（弱电侧，不碰强电）
> ② **不引入卫星/北斗**，全部走地面通信链路
> ③ 60 分钟、4 人、评委只看不问、装置要占地方

---

## 0. 先解决一个结构性难题

弱电机柜有个天然劣势：**它长得像个箱子，而箱子不唬人**。而且"机柜 + 交换机 + K8s"很容易被专家一眼判定成**实训室**。

所以本轮所有方向都额外加两条硬性设计约束：

| 约束 | 具体做法 | 解决什么 |
|---|---|---|
| **用手做工，肉眼可见** | 机柜区之间用**光缆/铜缆真实互连**：现场做光纤熔接、端面清洁、OTDR 插损测试、配线架跳线、水晶头端接、线缆绑扎入槽 | 机柜最容易丢的正是第 2 类（设备维护）与第 6 类（网络运维）的"手上功夫"分 |
| **装置要扩成一堵墙** | **3 联柜**：①网络柜（ODF+交换机+防火墙）②算力柜（3 节点信创服务器 + K8s LED 灯阵）③业务柜（网关/终端/告警面板）；柜顶通长线槽 + 侧面立式监控臂 + 移动处置席 | 把 1 个箱子变成 3 米宽的"机房切片"，占地与体量一次性解决 |

> 一句话：**机柜不是装置，机柜是舞台。真装置是"柜间链路 + 柜上业务"。**

## C. 三强详解（下一轮可深挖的三个）

### 🥇 N11 园区零信任准入与横向渗透对抗演练平台
**为什么最强**：唯一同时把"网络安全（第 3 类）+ 网络运维（第 6 类）+ 数据（第 4 类）+ 移动端（第 1 类）"全部变成**现场可视动作**的方向；且"攻防"天然自带紧张感与叙事性，60 分钟不会无聊。

- **装置**：3 联柜 —— ①安全柜（防火墙/微隔离/堡垒机/态势感知）②网络柜（核心交换 + 接入 + ODF + 光跳线）③业务柜（信创服务器 + 靶标业务系统 + 移动端投屏）
- **60 分钟主线**：合规基线核查 → 攻击链打穿（弱口令 → 横向移动 → 数据外带）→ 现场研判（抓包/日志/流量）→ 策略下发（微隔离/ACL/准入）→ 复测证明收敛 → 移动端生成安全报告并推送
- **故障注入**：接入违规终端 / ARP 欺骗 / 镜像口分析 / 拔网线导致策略失效
- **⚠️ 风险**：渗透测试的**合规边界**必须先写清（仅限自建靶标、场内授权、不触碰真实公网目标）。答辩一定会问。

### 🥈 N15 跨域算力调度与一体化算力服务平台
**为什么强**：最贴"软件和信息技术服务业"这个大类的正统形态，K8s + 信创 OS + IaC + 可观测性 = 技术先进性直接拉满；东部算力枢纽、算力券是 2026 年前后的政策热词。

- **装置**：3 节点信创服务器 K8s 集群 + 存储 + 交换机 + LED 灯阵（**灯阵是视觉证据**：Pod 调度肉眼可见）
- **60 分钟主线**：集群初始化（IaC 脚本一键起）→ 部署业务微服务 → 发起算力申请（移动端）→ 调度器分配 → 压测触发 HPA 扩容 → 计量出账 → 大屏展示多集群算力水位
- **风险**：动手做工偏弱（都是敲命令/跑脚本），必须靠"光纤/铜缆链路自建"补第 2、6 类岗位群，或与 N16 合并（加混沌工程注入）。

### 🥉 N18 5G 专网 + 网络切片端到端保障（需运营商合作）
**为什么强**：能一次性做出"主链路正常 → 断纤 → 自动切 5G 保业务不中断"这种**评委最爱看的瞬间**。淮北工业学校靠 5G-A 拿了银奖，说明这条线评委认可。

- **装置**：5G CPE + 边缘 MEC + 切片管理平台 + 光纤主链路（现场可拔）
- **风险**：频段与专网设备依赖运营商，成本和排期不可控。**没有企业背书不建议自上**。

## D. 组合拳建议（比单选更有胜算）

> **N11 为主 + N16 为副 + N19 为工法**
> = 零信任安全运营 + 混沌工程故障自愈 + 全光链路自制

一套 3 联柜装置同时说三件事：**"网是我们自己铺的"**（第 2、6 类）、**"云是我们自己运维的、还会自愈"**（第 6 类）、**"安全是我们自己打自己守的"**（第 3 类），
移动端 App 作为**唯一的用户交付界面**串起全部（第 1 类），数据侧用**指标/日志/流量三库**承接（第 4 类）。
→ 目标覆盖 **6/7，且第 2、6 类从"讲"变成"做工"**，彻底摆脱"实训台"嫌疑。
