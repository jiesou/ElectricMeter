# 中兴（ZTE）5G 移动互联产品线 · 型号命名体系说明书

> 目的：一眼判断某个中兴型号是什么**形态**、什么**档次**、第几**代**。
> 证据分级：**【官方一手】** = 中兴官网/官方新闻稿/官方支持页·快速指南 PDF；**【媒体】** = IT之家/快科技/新浪等；**【电商】** = 京东/淘宝/中兴商城商品页；**【社区推断】** = 拆解/论坛/UP 主。
> 凡是推断，一律标注；不确定的写「未确证」，不编。

---

## 0. 三句话答案（先给用户的质疑）

1. **命名不是瞎写，是「两台名字并排写在同一份文件里」——同一台硬件，两个标签。** MC/MU/MF 是**工程/运营商/合规标签**（招投标、进网许可、FCC/CE 备案、TR-069 网管全用它）；G/U/F/K 是**消费零售标签**（2024 年起）。铁证：中兴官方支持页的手册标题直接写成 `G5 Pro (MC8512) 快速指南`、`U60 Pro(MU5250) 快速指南`；中兴自己撰写的 G5 Max 产品说明标题就是 `G5 Max(MC7520)`。**所以「G5 一会儿又 MC888」不是混乱，是同一代产品的两张脸。**
2. **「G5」不是「5G」，是「第五代」**——中兴官网把 G5F 写作「第五代 5G 室外 FWA」、把 G5B2 写作 "The 5th-Generation 5G Indoor FWA"。同理 G6 = 第六代。**字母管形态，数字管代数，后缀管档次。**
3. **品类当然更多，而且有清晰的价格阶梯。** 你之前看到的 12 个型号只是「带网口」那一小撮。**中兴 5G CPE（带 RJ45）目前最低门槛是 G5TS 699 元 / G5TS Pro 869–899 元**；三四百元档有的是**5G 随身 WiFi（无网口）**，如 F50 Pro 399、V50 399、U30 Air 314–469、M3 379。

> **一个必须知道的坑**：中兴官网把两条标签轨的产品**混在同一个列表里卖，却从不给出对照表**——这是它官网的呈现问题，不是命名本身没有逻辑。想知道某台 G/U/F 的真实 MC/MU 代号，去 `ztedevices.com/cn/supports/<零售名小写>/` 看手册标题的括号。

## 1. 型号结构的「语法」

```
[ 形态前缀 ] [ 代数/规格数字 ] [ 档次后缀 ]
    MC / MU / MF / G / U / F / K / M / V / S
```

### 1.1 字母前缀 → 形态（核心表）

> **MC / MU / MF 三个字母的中文展开，中兴从未公开定义，属【社区推断】。但「功能对应」是一手可证的**——中兴自己在 FCC 备案里填写的 Equipment Class（申请人 = ZTE Corporation）：
> - `SRQ-MC801A` → **"5G CPE** with WCDMA, LTE, 5GNR and WiFi"；`SRQ-MC7010` → "5G Wireless Router" → **MC = CPE/路由器**
> - `SRQ-MU5001` → **"UFI** with LTE and WiFi" → **MU = UFI（随身 WiFi）**，**不是 "USB"**
> - `MF286C3`="LTE CPE"、`MF833U`="LTE USB Dongle"、`MF993C`="LTE UFi" → **MF = 4G 全品类不分类**

| 前缀 | 形态 | 典型外观 | 有 RJ45 网口？ | 例证（官方一手） |
|---|---|---|---|---|
| **MC** | **5G CPE / 路由器** | 立式/书本式，DC 供电，无电池 | **有** | MC801→MC801A→MC8020→MC888→MC889(室外)→MC8500/8512/8531 |
| **MU** | **5G 随身 WiFi / UFI** | 口袋大小，内置电池 | **绝大多数无**（MU5001 例外，有 1 个 GE 口） | MU5001/MU5120/MU5250/MU5350S/MU5353/MU5353D/MU5650/MU3350S/MU3356/MU3650/MU3351 |
| **MF** | **4G 全品类老线**（4G CPE + UFi + USB 卡） | — | 视型号 | MF286C3(LTE CPE)、MF296C/MF293N(4G 路由)、MF833U/MF863(4G Dongle)、MF928/MF993C/MF935(4G UFi)、MF18A(Mesh) |
| **G** | **5G 室内/室外 FWA**（零售主线，**G = 5G FWA，数字 = 第几代**） | 立式 CPE | **有** | G5 / G5C / G5TS / G5TS Pro / G5 Air / G5 Plus / G5 Max / G5 Max WiFi / G5 Ultra / G5F(室外) / **G6 Ultra / G6 Max**(第六代) |

| **S** | **卫星通信终端**（天通猫） | 手持 | **无** | S60 Pro（天通卫星猫） |
| **C** | **摄像头** | — | — | C10L（4G 摄像头） |

> **两条重要边界：**
> 1. **关键分界线是「4G → 5G」，不是「CPE → USB」**：4G 时代统统叫 MF；到 5G 才按形态拆成 **MC（CPE）+ MU（随身）**。别被 `MF833U`/`MF927U` 的尾巴 U 迷惑——那是尾部变体字母，与作为第二字符的前缀 U 不是一回事。**【推断·高置信度】**
> 2. **G/U/F/K 的「字母=形态、数字=代数」也不是官方声明**，是从官网信息架构（官方把产品分成 5G FWA / 5G MBB / 4G FWA / 4G MBB / Industry IoT）与官方文案归纳的强规律。中兴 2G/3G 时代还用过单字母体系（G 系列 GPRS 数据卡、MU 系列 TD 数据卡），字母在历史上被重用过，**老型号不能硬套新规律**。**【推断】**

### 1.2 数字部分 → 代数 / 规格

**MC 系列的 4 位数字不是连续序号，是「平台/档次段位」：**

| 数字段 | 含义 | 例证 |
|---|---|---|
| **7xxx** | **室外 CPE** | MC7010（户外 5G CPE，PoE）、MC7520/MC7523（= G5 Max 的海外/国内型号码） |
| **8xxx** | **室内 CPE 主力段** | MC801 / MC801A / MC801A1 / MC8020 / MC888 / MC889(室外) / MC8500 / MC8512 / MC8531 |
| **8x0x** | **第一代平台** | MC801、MC801A、MC801A1、MC8020 |
| **8x8x** | **第四代平台** | MC888、MC888S、MC888 Pro、MC888 Ultra、MC889、MC889 Pro |
| **85xx** | **第五代平台**（85 呼应 G5） | MC8500（G5TS Pro）、**MC8512（G5 Pro）**、**MC8531（G5 Ultra）** |

> **别指望 MC 数字是连续序号**：`801 → 801A → 8020` 这段是严格递增的，但 `8020 → 888` 是**换营销号段**（888 中文语境吉利），`888 → 85xx` 又**换了一次**（85 呼应 G5）。**所以「数字大小 ≈ 代数」只在同号段内部成立，跨号段只能用上表「代数链」判断。**【推断·高置信度】

**MU 系列的 4 位数字同样是段位：**

| 数字段 | 含义 | 例证 |
|---|---|---|
| **5xxx** | **5G MiFi 主力** | MU5001、MU5002、MU5120、MU5250、MU5252、MU5350S、MU5353、MU5353D、MU5358、MU5650 |
| **3xxx** | **5G 卡片/入门 MiFi** | MU300（F50）、MU3350S、MU3351（V50）、MU3356（F50 Pro）、MU3650（F40） |
| **xxxD 后缀** | 同平台的**升级/渠道变体** | MU5353（U30 Pro）→ **MU5353D（M3 Pro）**；MU5650 → MU5650D |

> 【官方一手（各代际表述）+ 推断（两条线代数不同步的归纳）】

> **这就是「MC 和 G 为什么并存」的答案：它们是同一台硬件的两个标签，不是两条产品线。**
> - **工程/运营商轨（MC/MU/MF）**：招投标、**进网许可**、FCC/CE 备案、TR-069 集中网管、BOM —— 这些接口都要求型号**长期稳定可追溯**，所以运营商线沿用 MC。

## 4. 中兴视通 / 中兴终端 / 渠道定制 的关系

| | 中兴终端（ZTE Mobile Devices） | 中兴视通（Seecom） |
|---|---|---|
| 官网 | ztedevices.com / ztemall.com | seecom.com.cn |
| 身份 | 中兴通讯的**终端产品事业部** | **中兴通讯全资子公司**【官方自述】 |
| 干什么 | 造硬件、定义型号、开发布会 | **MVNO 虚商 + 物联网 + 渠道分销**：号码套餐、靓号、话费充值、物联网卡 |
| 卖什么 | 全部终端产品线 | 挑选部分硬件 + **绑套餐卖** |

**为什么 M3 / M3 Pro 不在中兴终端产品目录里？**

事实（**官方一手**）：
- M3 与 M3 Pro **有官方支持页**（`/cn/supports/m3-pro/`，页面日期 2026-01-08，附软件下载），说明是**中兴正规产品，不是山寨**。
- 但它们**不在** `ztedevices.com/cn/products/mobile-internet/` 产品目录里；也**不在**中兴视通官网的「智能硬件」清单里。
- 京东把 M3 挂在「**流量大师**」类目，与 U30 Pro / U30 Air 混编。【媒体/电商】
- **M3 Pro = MU5353D，而 U30 Pro（焕新版）= MU5353，同一平台家族。**【官方一手】→ 强烈提示 M 是**同一硬件的渠道专属命名**。

**结论（【推断·中置信度】）**：M 系列是**面向渠道/流量套餐的 SKU 线**——用「流量大师」这类渠道话术包装、绑套餐卖，型号名换了以避免与零售 U 系列正面比价。**M3 不是「另一个品牌」，本质是 U 系列的一个渠道变体。**
同理，`5G CPE 2 PRO`、`5G CPE 3 Pro`、`TOPFLOW 直播神器`、`流量大师` 都是**同一硬件的不同销售名**。

> **诚实边界**：「M3 由中兴视通操盘」这一说法**我没有取到任何一手证据**——视通官网硬件清单里没有 M3。所以只能说「M 是渠道线」，**不能说「M 就是视通的」**。同样，「中兴视通是否为中兴全资子公司」在中兴年报「主要控股参股公司」里**未逐页核到**（该表述来自视通官网自述）。【未确证】

## 6. 用户原话质疑的逐条回答

> 「我看不出一个很成体系的。这命名规律也很奇怪：G5，一会儿又 MC888。这型号跟瞎写的一样，没有很成体系，没有品类的感觉。」

**答**：
- **不是瞎写，但也确实不是「一条干净的体系」——它是一条体系 + 一套标签。**
  真正的体系只有一条：**字母管形态、数字管代数、后缀管档次**（MC=工业名 / G=5G FWA 第 n 代 / U=随身 / F=卡片 / K=入门 CPE / M=渠道）。乱的感觉来自**中兴把「工程名」和「零售名」两个 label 混在同一个产品列表里，且从不给对照表**：同一台机器，运营商备案和网管里叫 `MC8512`，你在京东上看到的是 `G5 Pro`。中兴自己的支持页甚至把两个名字并排印在手册标题上——`G5 Pro (MC8512) 快速指南`。
- **「G5 一会儿又 MC888」的正解**：这两个**根本不是同一代**，也不是竞品。MC888 是**第四代**（2022，官方原话「已经迭代到第四代产品」）；G5 是**第五代**（2024 起）。**「G5」的 5 就是「第五代」**，不是「5G」——中兴官网写「**第五代**5G室外FWA 中兴G5F」，把 G5B2 标为 "The **5th-Generation** 5G Indoor FWA"。同理 G6 = 第六代。
- **品类比你看到的多得多，但你的目标组合不存在。** 110 个官方支持页里有 30+ 个移动互联型号，从 69 元的 F30 Pro 到 2399 元的 G5 Ultra 都有。但**「三四百元 + 带 RJ45 网口的 5G CPE」这个组合在中兴产品线里没有**：
  - 带 RJ45 的 5G CPE，**中兴目前最低门槛是 G5TS 699 元 / G5TS Pro 869–899 元**（淘宝 2026-09 已见 G5TS Pro 669）。
  - 三四百元档能买到的是**无网口的 5G 随身 WiFi**（F50 Pro 399、V50 399、U30 Air 314–469、M3 379）；F40/U25/U25S 是更便宜的 **5G RedCap**（149–199）。
  - 这一点对你的「第零路外网接入」是**硬伤**：要 RJ45 就得接受 700 元起步，或退回二手 MC888S / MC801A（京东该价位段基本是 95 新二手，无官方全新在售）。

## 7. 与本文相关、但上文未展开的边界（诚实清单）

- **中兴从未公开命名规则文档**。本文的「前缀→形态」表是**归纳**，非官方声明。**最有价值的可验证锚点是官方支持页的 URL 与手册名**（`/cn/supports/<型号小写>/`，手册名形如「G5 Pro (MC8512) 快速指南」；部分 URL 会 301 成 `/supports/<零售名><代号>/`）——**想知道某台 G/U/F 的真实内部型号码，就去查这一页，性价比最高**。
- **芯片列大面积为第三方来源**。中兴只写「4nm 四核 2.2GHz 5G 芯片」「中兴自研国产 5G 芯片」，**官方不公布 5G 基带型号**。G5 Pro = 联发科 T830 是【社区】口径，F50 = 展锐 T760 是【拆机】口径。
- **3C 认证 / 工信部入网库：本次未取到。** 工信部电信设备进网管理 `jwxk.miit.gov.cn` 抓取只得到空白 SPA 外壳（需浏览器交互/验证码）；`cx.cnca.cn` 需交互式表单。**替代性的一手合规证据改用 FCC EAS 备案库**（中兴自己提交、可全文检索、可下 PDF）：<https://fccid.io/SRQ>。网上流传的「G5 Pro 进网许可证编号 17-6467-243277」**仅有二手来源，请勿当事实使用**。
- **未确证项（不要当结论用）**：
  - MC/MU/MF 三个字母的**确切英文展开**（只确证了功能对应）。
  - **G5 Ultra = MC8531** 只有香港零售商与手册镜像站，**中兴官网未确认**。
  - **MC7523 与 MC7520 的区分**（MC7523 仅一处电商文案指向 G5 Max）。
  - **F50 的内部型号码有冲突**：官方支持页列 `MU3350S`（有独立手册页），但京东商品标 `MU300`；**无任何页面把 MU3350S 与 F50 关联**。
  - **U25S = MU5650**：MU5650 是官方独立手册页，但无页面把它与 U25S 关联（U25 的快速指南 PDF 内文写的是 `MU5650D`）。
  - MC801A1 / MC888S 的正式发布年份；M3（非 Pro）的内部型号码。
  - **M3 / M3 Pro 是否由中兴视通操盘** —— 视通官网硬件清单里**没有** M3，此说法**无一手证据**。
  - 「A / A1 = 运营商定制版」——**无一手出处**。
  - 「S = 简化版 / 升级版」——**两个方向都被实证反驳**：MC888S 的 Wi-Fi 峰值（3000Mbps）低于基线 MC888（3600Mbps），但带机量（128 vs 32）和网口（4 个 vs —）**多于**基线，且专为 700M 优化。**S 只能判为「本地化/变体版本」。**
- **MC888S、MC801A、MC8020、MC888 系列的官方接口表未取到**——中文官网「参数规格」标签页是 JS 渲染，抓不到正文。上表中这几行的网口/天线口标为「未查到」。**（英文官网 `/en/products/mobile-internet/5g-fwa/*.html` 是服务端渲染、有完整官方文案——这是继续补齐的最优入口。）**
- **MC888S 的官方支持页未列出官方售价**，本文价格列标为「二手/清仓档」。
