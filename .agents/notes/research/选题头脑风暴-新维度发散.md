# 选题头脑风暴（第四轮）：换维度发散 —— 按"场景经济形态"切

> 前三轮已覆盖：岗位群矩阵（第二轮）、弱电机柜 20 方向 · 六原型（第三轮）
> 本轮刻意**不按技术栈分类**，改用"场景经济形态"作为新坐标轴，尽量与已提 30 个方向不撞。
> 骨架约束沿用：19" 机柜 / 网云为骨、纯地面通信、60 分钟、4 人、装置要占地方。
> 评分：岗位群覆盖（7 类）/ 创新度 / 撞题风险。

---

## 组 A｜智能体经济（Agent 与自主执行）

> 第 3 轮里 AI 只出现在"N12 安全网关"和"N17 AIOps"，且都是**辅助分析**。
> 突破口：让 AI **真正执行动作**（Agent 自主排障、自主调度），而不只是给建议。

| # | 场景 | 业务闭环 | 覆盖 | 创新 |
|---|---|---|:--:|:--:|
| **N21** | **AI Agent 自主运维值班员** | 告警风暴涌入 → Agent 读日志/指标 → 自主决策并执行修复剧本（改配置、重启、扩容）→ 人工审批留痕 → 移动端推送处理报告 | 6.0 | ★★★★★ |
| **N22** | **多智能体协同的客服与工单中枢** | 语音/文字进线 → 意图识别 Agent → 派单 Agent → 外勤 Agent → 质检 Agent，全链路可视 | 5.0 | ★★★★ |
| **N23** | **AI 视觉质检产线边缘部署**（已知案例多，需换角度：做**模型下发与边缘运维**而非模型本身） | 中心训练 → 模型打包 → 边缘节点 OTA 下发 → 推理监控 → 精度劣化自动回滚 | 5.5 | ★★★ |
| N24 | **具身智能/机器人远程遥操作与本体运维** | 远端机器人 + 低时延回传链路 + 遥操台 + 本体健康监测 | 5.5 | ★★★★★ |

**N21 的本体优势**：把"AI 应用"和"自动化脚本运维"合成一个动作——**Agent 动手改配置**，这是评分表里"技术先进性 + 自动化脚本运维"的最直接命中，且几乎没人这么做。

## 组 B｜数据要素与可信流通（数据从"分析"升级为"资产"）

> 前三轮数据侧都是"采集—入库—可视化"。突破口：**数据作为可交易资产**的合规流通。

| # | 场景 | 业务闭环 | 覆盖 | 创新 |
|---|---|---|:--:|:--:|
| **N25** | **隐私计算 / 联邦学习跨域数据协作平台** | 两方（或三方）本地数据 → 联邦训练，原始数据不出域 → 联合模型效果对比大屏 → 移动端审批授权 | 5.5 | ★★★★★ |
| **N26** | **数据资产登记与场内交易撮合** | 数据目录挂载 → 分类分级打标 → 脱敏与沙箱 → 授权审批 → 计量结算与审计存证 | 5.5 | ★★★★★ |
| N27 | 数据标注众包 + 隐私脱敏流水线（升级 N9） | 脱敏 → 分发 → 标注 → 质检 → 版本交付 | 4.5 | ★★ |

**N25 的赛场优势**：现场"两柜两台服务器各持一半数据、联合算出结果却都不泄露原始数据"是个**极好的可视化瞬间**；
且直接命中"数据要素×三年行动计划"和"东数西算"的政策叙事，应用价值 10% 好讲。

## 本轮最值得单独拎出来的四个

1. **N21 AI Agent 自主运维值班员** —— 把 AI 应用 + 自动化脚本运维合成一个动作，Agent 真的动手改配置，评分表两项直接命中。

4. **N28 XR 远程协作** —— 唯一让第 1 类岗位群（移动端设计/前端开发）当主角的方向，网络质量直接变成用户可感知的画面。
