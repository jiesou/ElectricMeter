### P1《港通·岸电与微网一体化运行管控系统》

#### 1.1 场景故事（30 秒版）

> "宁波舟山港年货物吞吐量全球第一，靠港船舶辅机烧油污染严重。我们为港口建了一套岸电+微网系统：船一靠泊，系统自动识别船型、匹配电压频率、接电计量、结算，同时光伏、储能、充电桩协同调度，让港口每一度电都来自绿色能源。"

#### 1.2 装置布局（占地 3m × 2m）

```
┌─────────────────────────────────────────────────────────────┐
│                    大屏（3D 孪生 + 能量流）                    │
├──────────────┬──────────────────────┬───────────────────────┤
│  A 区 岸电   │    B 区 微网机柜     │    C区 处置席         │
│  ·岸电箱     │   ·19"标准机柜       │   ·平板 + 真机        │
│  ·接插件     │   ·边缘网关          │   ·App 巡检/工单      │
│  ·电表      │   ·SDN 交换机        │   ·声光联动          │
│  ·模拟船体   │   ·信创服务器        │   ·充电桩模型        │
│  ·电压/电流  │   ·K8s 节点         │   ·光伏板 + 储能     │
│    互感器    │   ·北斗短报文终端    │                       │
└──────────────┴──────────────────────┴───────────────────────┘
```

#### 1.3 闭环链路

| 环节 | 具体动作 | 技术载体 |
|---|---|---|
| **数据采集** | 电表实时计量、光伏/储能状态、船舶接入检测、环境温湿度 | Modbus-RTU / MQTT → 边缘网关 |
| **研判分析** | 负荷预测、能量调度优化、船舶用电需求匹配、异常检测 | Python + InfluxDB + 轻量 AI 模型 |
| **任务调度** | 光伏优先→储能补充→电网兜底；充电桩有序充电；工单自动派发 | RabbitMQ + 规则引擎 |
| **现场处置** | 远程接电/断电、充电桩启停、声光告警、App 一键处置 | 平板 App + 声光 + 继电器控制 |

#### 1.4 岗位群覆盖

| 岗位群 | 可视动作 | 覆盖 |
|---|---|---|
| 1 移动开发 | 真机 App 扫码巡检、工单派发、遥测曲线 | ● |
| 2 设备维护 | 台架接线、互感器安装、串口调试、更换模组 | ● |
| 3 安全 | 渗透测试、抓包重放、告警联动、等保合规 | ● |
| 4 数据 | 数据入湖、清洗、时序库、可视化、AI 训练 | ● |
| 5 通信服务 | 客户解决方案讲解、工单/CRM、品质管控 | ○ |
| 6 网络运维 | 光纤/网线端接、VLAN 规划、SDN 策略、故障排除 | ● |
| 7 卫星 | 北斗短报文授时定位、兜底上报 | ● |

**覆盖分：6.5 / 7**

## 二、5 个新创意方向

### N1《冷链集装箱状态监控与溯源系统》

**场景**：宁波舟山港冷链集装箱运输，温度断链即货损。系统实时监控温度、湿度、位置、门开状态，AI 预测断链风险，自动告警并调度处置。

**装置**：集装箱模型 + 温湿度传感器 + GPS + 门磁 + 声光 + 平板

**覆盖分：5.5 / 7**（缺 3 安全、7 卫星）

**亮点**：宁波港口特色强，冷链货损痛点真实，AI 预测有技术深度。

## 四、Top 2 候选对比与推荐

### P1 vs P3 对比

| 维度 | P1 港通·岸电 | P3 擎云·园区网络 |
|---|---|---|
| **场景稀缺性** | 高（港口岸电全国少） | 中（网络运维较常见） |
| **视觉冲击力** | 强（强电 + 光伏 + 储能） | 中（机柜 + 线缆） |
| **技术深度** | 高（能量调度 + AI） | 高（SDN + 信创云） |
| **企业背书难度** | 中（需港口企业） | 低（园区通用） |
| **成本** | ~24,000 | ~25,000 |
| **被判"实训台"风险** | 低 | **高** |
| **60 分钟充实度** | 高（强电操作多） | 中（网络配置较抽象） |
| **宁波区域契合度** | **极高**（宁波舟山港） | 中（通用园区） |

### 推荐排序

1. **P1《港通·岸电与微网一体化运行管控系统》** — 场景稀缺、视觉强、宁波契合度高、被判实训台风险低
2. **P3《擎云·园区信息通信网络运行维护服务平台》** — 技术覆盖最均衡，但必须做成服务合同
3. **P2《星链兜底·海岛配网末端与应急通信运维系统》** — 卫星特色最突出，但场景背书难度高
4. **N3《低空经济无人机巡检与反制系统》** — 技术最先进，但成本和合规风险最高
